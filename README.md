# 打盹儿 (Snooze)

[![MaiBot SDK v2](https://img.shields.io/badge/MaiBot-SDK%20v2-blue)](https://github.com/Mai-with-u/maibot)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

让 MaiBot 模拟人类作息的睡眠管理插件，支持会话隔离与“起床气”情绪注入。

## 功能特点

- **作息模拟**：通过概率模型模拟“熬夜”、“贪睡”、“补觉”等真实行为
- **消息拦截**：在“睡觉”状态下完全静默，不消耗 LLM Token
- **被 @ 吵醒**：累计 @ 次数达阈值后，概率吵醒并进入“生气”状态
- **起床气注入**：生气状态下，自动在用户消息前注入自定义语气前缀
- **会话隔离**：不同群聊和私聊的状态完全独立，互不干扰
- **黑白名单**：支持按群聊/私聊分别设置生效范围

## 预设消息

在状态变更时，插件会自动发送以下预设消息（不经过 LLM）：

| 触发场景   | 发送消息     |
| :--------- | :----------- |
| **睡醒**   | `早ﾉ☀`       |
| **入睡**   | `Zzz🌙`      |
| **被吵醒** | `白金吵闹💢` |

## 安装

1. 将插件文件夹克隆到 Maibot 的 plugins文件夹内
2. 重启 MaiBot 或执行热重载

## 配置项说明

### 过滤

| 配置项         | 类型      | 默认值        | 说明                                    |
| -------------- | --------- | ------------- | --------------------------------------- |
| `group_filter` | str       | `"whitelist"` | 群聊过滤模式：`whitelist` / `blacklist` |
| `group_ids`    | List[str] | `[]`          | 群聊 ID 列表，例如 `["123456789"]`      |
| `pm_filter`    | str       | `"whitelist"` | 私聊过滤模式：`whitelist` / `blacklist` |
| `pm_ids`       | List[str] | `[]`          | 用户 ID 列表，例如 `["987654321"]`      |

### 起床

| 配置项            | 类型  | 默认值    | 说明                                         |
| ----------------- | ----- | --------- | -------------------------------------------- |
| `slot_minutes`    | int   | `30`      | 时间片段大小（分钟），所有定时判定以此为单位 |
| `wake_start`      | str   | `"07:00"` | 起床时间，开始进行贪睡判定                   |
| `snooze_prob`     | float | `0.3`     | 贪睡概率（0~1），命中则继续睡一个片段        |
| `force_wake_time` | str   | `"11:00"` | 强制起床时间点                               |

### 睡觉

| 配置项             | 类型  | 默认值    | 说明                                  |
| ------------------ | ----- | --------- | ------------------------------------- |
| `sleep_start`      | str   | `"21:00"` | 睡觉时间，开始进行熬夜判定            |
| `stay_prob`        | float | `0.2`     | 熬夜概率（0~1），命中则继续熬一个片段 |
| `force_sleep_time` | str   | `"04:00"` | 强制睡觉时间点                        |

### 吵醒

| 配置项           | 类型  | 默认值            | 说明                                                |
| ---------------- | ----- | ----------------- | --------------------------------------------------- |
| `ping_threshold` | int   | `3`               | 吵醒阈值：首个 @ 后一个片段内累计达到该次数触发判定 |
| `ping_wake_prob` | float | `0.6`             | 吵醒概率（0~1），达到阈值后每次新 @ 命中的概率      |
| `angry_prefix`   | str   | `"你被吵醒了..."` | 生气状态下注入 LLM 的前缀文本                       |
| `anger_slots`    | int   | `1`               | 消气时间（片段数）                                  |
| `resleep_prob`   | float | `0.2`             | 补觉概率（0~1），吵醒状态下每片段命中的概率         |

## 状态说明

### 主状态（3种）

| 状态     | 行为                                 |
| :------- | :----------------------------------- |
| **清醒** | 正常响应，不干预 LLM                 |
| **睡觉** | 拦截所有 LLM 调用，静默不回复        |
| **吵醒** | 响应消息，根据副状态决定是否注入前缀 |

### 副状态（仅主状态为「吵醒」时有效）

| 状态     | 行为                                 |
| :------- | :----------------------------------- |
| **生气** | 注入 `angry_prefix` 到用户消息最前面 |
| **消气** | 不注入，正常响应                     |
